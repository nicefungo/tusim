## Audit notes

- The ready candidates were re-audited against current code and executable evidence. Existing major compute/dataflow/precision/topology sweeps already have runtime modes or documented model limitations.
- No realistic alternative was removed because it lost a local benchmark. NONE remains the backward-compatible compression default despite RLE's large gains on clustered data.
- `docs/exploration/TERMS.md` remains pre-existing untracked user work and was not modified or included in this heartbeat.
- Adaptive compression preserves NONE and explicit RLE as materially useful alternatives: fixed-function ASICs can avoid codec cost, controlled software stacks can omit the frame, and heterogeneous runtimes can choose bounded per-tensor fallback.
- Context retention alternatives are preserved rather than selecting the lowest-latency row. Full save supports transparent preemption; live-prefix save supports compiler/runtime liveness contracts; control-only supports low-area hardware that reloads scratchpads.
- Baseline infrastructure issue fixed: `test-asm` no longer depends on undocumented `/tmp` files, so a clean `make test-quick` is reproducible.
- The structured-sparsity audit corrected a stale existence claim: the module was tracked but omitted from `TU_OBJS` and all test aggregates. It is now executable through focused targets. Dense remains the default because it avoids pruning error and sparse-control cost.
- Decoder provisioning is now explicit rather than assuming infinite decode bandwidth. The measured narrow-N row demonstrates why 2:4 cannot be summarized as an unconditional 2x speedup.
- The bitmap audit compared identical random and clustered patterns rather than treating scalar sparsity as sufficient evidence. Bitmap, RLE, raw, two-way adaptive, and three-way adaptive modes are all retained because their hardware and workload regimes differ.
- The three-way selector minimizes payload bytes, not end-to-end latency. Decoder throughput, FIFO stalls, area, and power remain explicitly unquantified; no universal codec recommendation is made.
- Decoder throughput is now executable rather than assumed infinite. The common dense-output lane plus codec metadata-rate abstraction covers materially distinct low-area through extra-wide hardware and streaming versus staged placement without inventing physical area/power numbers.
- The decoder sweep rejected the previous payload-only speedup implication: 1–8 output/cycle decoders are 2–16× slower than raw in this workload, 16/cycle generally breaks even, and 32/cycle yields up to 2× lower load latency only in measured sparse regimes. Traffic savings remain valuable even when latency does not improve.
- A new direct compressed-domain compute candidate is intentionally blocked: current RLE/bitmap streams reconstruct dense SRAM and cannot honestly stand in for sparse token delivery to MMA.
- The interconnect audit separated switching from topology. The prior topology sweep had silently assumed store-and-forward and multiplied full payload serialization by hop count; its universal MESH recommendation is now explicitly superseded by traffic-matrix results.
- Cut-through, store-and-forward, and the legacy timing lower bound are all preserved. Cut-through wins measured long-route tensor transfers but adds VC/credit/deadlock complexity; store-forward remains plausible for simple fabrics and bridge boundaries.
- Focused static multicore verification exposed two latent defects: an FP16 interpretation of the FP32 O-buffer and dataflow registry replacement that could invalidate prior core pointers. Both remain covered by the multicore suite.
- The 2026-07-24 contention audit implements ideal-parallel and shared-directed-link lower bounds rather than selecting one fidelity level. At 16 cores the MESH is 55.4% lower for all-to-all but 48.6% slower for hotspot fan-in under deterministic XY; topology selection is workload- and routing-dependent.
- Shared-link accounting is explicitly not a queue simulator. Finite FIFO depth, injection timing, arbitration, head-of-line blocking, adaptive routing, collective algorithms, and router area/power remain unmodeled rather than assigned invented costs.
- The 2026-07-25 route-order audit preserves deterministic XY and YX rather than retaining only the locally faster row. YX cuts the 4×4 top-row-to-left-column lower bound from 2,334 to 798 cycles, while XY gives the same gain for the transposed workload; symmetric all-to-all is unchanged.
- Fixed YX closes the evidenced deterministic route-order gap without pretending to be adaptive routing. Queue-aware adaptive routing remains blocked on injection, arbitration, virtual-channel, backpressure, and deadlock contracts grounded in compiler or collective traces.
- The 2026-07-26 dataflow re-audit invalidates the historical WS/OS/RS ranking as comparative evidence. It proves direct-global selection, canonical arithmetic, edge geometry, K-tile callback counts, and runtime pipeline depth, but labels timing only as an uncalibrated deterministic estimate. OS is lowest at depth 2 in the measured matrix while RS is lowest at depth 1 because of OS's ad hoc fetch term; no universal mode is selected.
- The 2026-07-27 per-core dataflow study closes the selection/isolation contract: WS, OS, and RS survive independent core swaps, produce byte-identical outputs, retain distinct live cycle deltas, and reject NLR without fallback. This enables homogeneous versus heterogeneous mapping studies but does not model switch cost or parallel execution.
- Dataflow traffic observability remains blocked: define RF/SRAM/NoC event boundaries and overlap before adding bandwidth, energy, or physical-stationarity claims. Per-core plugin-private statistics are also blocked on ownership/snapshot semantics because registry objects are process-shared.
- The 2026-07-28 audit found a configuration-provenance defect in the existing power model: process and clock were silently inferred from array dimensions and DRAM bandwidth despite YAML advertising a power block. AUTO plus all six explicit process presets are retained; no node is selected as universally best because mask/NRE, yield, reliability, physical timing, and supply risk are absent from the scalar tables.
- Explicit clock selection is intentionally labeled a constant-voltage timing assumption, not DVFS. At fixed 7nm event counts, higher clock lowers modeled leakage duration but raises average power; voltage-dependent `CV^2`, feasible F-V points, transition cost, thermal response, and delivery constraints remain a BLOCKED future contract.
- Focused verification exposed stale shared-library selection in the historical `test-power` target. It now links `./libtucmodel.a` explicitly, so canonical-struct changes cannot be tested against an old `.so`.
- Remaining open candidates are blocked on architecture contracts, traces, or physical-model dependencies; no other verified READY item was found in this audit.
